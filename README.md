# CP Learning – Ôn HSG Tin học THPT

Website ôn HSG Tin học lớp 10, 11, 12 bằng HTML, CSS và JavaScript. Không cần cài thư viện hoặc chạy build.

## Nội dung

- Lộ trình riêng cho ba khối; 18 bài khởi đầu có gợi ý, lời giải và mã C++98.
- Thư viện đề bổ sung: nhập văn bản hoặc đính kèm PDF, DOCX, TXT, Markdown, ảnh.
- Theo dõi tiến độ, ghi lỗi, đồng hồ tự luyện và sao lưu/nhập kho đề.

## Triển khai GitHub Pages

Vào Settings → Pages → Deploy from a branch, chọn `main` và `/(root)`, rồi Save.

Tệp `index.html` nằm tại thư mục gốc. Các liên kết tài nguyên dùng đường dẫn tương đối, phù hợp website đặt trong đường dẫn repository.

## Dữ liệu

Tiến độ và đề bổ sung được lưu trên từng trình duyệt, chưa đồng bộ máy chủ. Trước khi đổi địa chỉ website, xuất kho đề và tiến độ từ địa chỉ cũ, rồi nhập tại địa chỉ mới. Quyền riêng tư của bản Sites không tự áp dụng cho GitHub Pages.
